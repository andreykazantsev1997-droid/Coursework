# Приложение для анализа личных финансов.

Курсовой проект представляет собой бэкенд-приложение на Python для обработки, 
фильтрации и анализа банковских транзакций из файлов Excel.

## Функционал проекта

### 1. Веб-страницы (`views.py`)
* **Главная страница:** Формирует JSON-ответ со следующими блоками:
  * `generate_main_page` — финальная функция, которая координирует работу других модулей, 
  агрегирует результаты и формирует итоговый JSON-ответ для Главной страницы.
  * 
### 2. Вспомогательный модуль утилит (`utils.py`)
* `load_excel` — загрузка транзакций из Excel-файла.
* `load_user_settings` — чтение пользовательских настроек (валюты, акции) из `user_settings.json`.
* `get_date_range` — вычисление временного диапазона с начала месяца по переданную дату.
* `filter_operation_by_date` — фильтрация транзакций из Excel под рассчитанный диапазон дат.
* `get_greeting` — динамическое определение времени суток и генерация приветствия.

### 3. Сервисы (Модуль `services.py`)
* `get_currency` — запрос актуальных курсов валют относительно рубля с API Центробанка РФ.
* `get_stock_prices` — получение текущей стоимости акций с API Московской биржи.
* `simple_search` — поиска транзакций по подстроке в полях «Категория» и «Описание».

### 4. Отчеты (Модуль `reports.py`)
* `get_cards_info` — расчет общих расходов и кэшбэка в разрезе каждой банковской карты с округлением до целых чисел.
* `get_top_cashback_categories` — вычисление ТОП-3 категорий расходов с максимальным начисленным кэшбэком.
* `spending_by_category` — выгрузка и фильтрация всех расходов по выбранной категории за последние 90 дней.

## Структура проекта

* `data/` — каталог с исходным Excel-файлом транзакций (`operations.xlsx`).
* `src/` — исходный код приложения (`main.py`, `views.py`, `utils.py`, `services.py`, `reports.py`).
* `tests/` — пакет с автоматическими Unit-тестами (`test_views.py`, `test_utils.py`, `test_services.py`, `test_reports.py`).
* `user_settings.json` — Настройки пользователя.

## Инструкция по установке и запуску

### 1. Установка зависимостей
Проект использует менеджер пакетов `Poetry` (или стандартный `pip`). Для установки всех необходимых библиотек (pandas, requests, pytest, mypy) выполните в терминале проекта:
```
poetry install
```

### 2. Запуск
Для запуска основного скрипта и вывода отформатированных JSON-данных выполните:
```
python src/main.py
```

### 3. Запуск тестирования
Для прогона Unit-тестов с использованием библиотеки `pytest` выполните:
```
pytest
```
